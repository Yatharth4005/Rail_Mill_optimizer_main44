# Supplied SPM sources included in this build

1. `data/reference/SPM Presentation .ppt` — SPM process/capacity/product/process information.
2. `data/reference/RAW MATERIAL LENGTH TOLERANCE.xlsx` — section-wise RM length tolerance and product/raw-size reference.
3. `data/reference/Grade details of ex grade and raw grade.xlsx` — external grade to raw-grade compatibility.
4. `data/reference/LFA BATCH DETAILS.xlsx` — batch, section weight, billet length and billet sectional weight reference.
5. `data/reference/all sections.zip` — original section planning workbooks.
6. `data/section_workbooks/` — extracted copy of the supplied section workbooks.

The application does not fabricate missing caster constraints. Live order data, heat sizes, chemistry-transition rules, actual rolling-loss coefficients and RM prices should be added/configured with plant data before production use.
